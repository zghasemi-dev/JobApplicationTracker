# Job Application Tracker

## Project Description
Job Application Tracker is a C# console application for managing job applications. The program allows users to add applications, view and filter them, sort them by application date, update their status, delete applications, and display statistics.

The project demonstrates object-oriented programming (OOP), collections, LINQ, input validation, and Git/GitHub version control.

## Features
- Add a new job application
- Display all applications
- Filter applications by status using LINQ
- Sort applications by application date
- Display statistics, including total applications, counts per status, and average response time
- Update application status
- Delete an application
- Find unanswered applications older than 14 days
- Validate user input

## Technologies
- C#
- .NET
- LINQ
- Git and GitHub

## How to Run
1. Install the .NET SDK.
2. Clone or download this repository.
3. Open a terminal in the project folder.
4. Run the following command:

```bash
dotnet run
```
